Connect Google Drive

  1. Create a Google Cloud project

    Open Google Cloud Console ↗. Create or select a project.

  2. Enable the Google Drive API

    Find Google Drive API in the API Library and enable it.

  3. Configure Google Auth Platform

    Set Branding and Audience. Add your email as a test user if your app is in testing.

  4. Create a Desktop app client

    In Clients, choose OAuth client → Desktop app, then download its JSON.

Good to know

What links work?

Public HTTP or HTTPS direct file URLs. Pages requiring cookies, sign-in, or interactive download buttons are not supported.

Where does the file travel?

Through this computer in small chunks, into Google Drive. Keep Relay running and the computer online.

Can I use existing folders?

Relay only accesses files and folders it creates. Choose My Drive or create a folder here.

What happens after a restart?

History and settings remain. Load your client JSON and connect again. Incomplete transfers restart from the beginning; source links are available only if you enabled saving them.

When do scheduled jobs run?

When their time arrives and Relay is running, signed in, and the queue is not paused. Overdue jobs wait until those conditions are met.
